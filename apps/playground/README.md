# Playground

Testpagina voor `@dafkedd/eid`.

```bash
npm run build            # vanuit de root: bouwt @dafkedd/eid
npm run bridge           # bridge met je echte kaartlezer (of: npm run bridge:mock)
npm run playground       # http://localhost:3000
```

Zonder bridge: http://localhost:3000/?mock=1 (virtuele kaart in de browser).
